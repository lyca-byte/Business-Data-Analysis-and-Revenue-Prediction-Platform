An end-to-end Machine Learning application that analyzes business data, visualizes relationships between key variables, and predicts revenue using a trained Linear Regression model.

Explore Data Analysis Try Prediction
Project Objective

This project demonstrates an end-to-end Machine Learning workflow — from synthetic dataset generation through exploratory data analysis, model training, and final deployment as a web application with a REST API backend.

Data Analysis Machine Learning REST API Web Application
Problem Statement

Businesses collect operational and marketing data, but raw data alone does not provide actionable insights. This platform demonstrates how business data can be analyzed, visualized, and used to build a predictive model that forecasts revenue from key business inputs.

Machine Learning Workflow
Dataset Generation → Data Cleaning → Exploratory Data Analysis → Feature Scaling → Train / Val / Test Split → Model Training → Validation → Final Evaluation → Model Saving → FastAPI Backend → Web Application

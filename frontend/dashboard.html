Feature Correlations with Revenue

Pearson correlation coefficient between each input feature and Revenue. Values range from -1 (strong negative) to +1 (strong positive). A value near 0 indicates a weak linear relationship.

previous_revenue has the strongest correlation (+0.824), meaning past performance is the best predictor of current revenue. discount_percentage has a weak negative correlation (-0.049) — discounts slightly reduce revenue as expected. product_price has near-zero correlation (+0.038) because its revenue effect is diluted by varying customer counts.
